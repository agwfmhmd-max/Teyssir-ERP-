# Teyssir ERP — تحديث استيراد Excel والشعار

## ما الذي أُضيف؟
- زر «استيراد بيانات Excel» يظهر بعد تسجيل الدخول إلى الشركة.
- استيراد موجّه للمنتجات والمخزون، الزبناء، الموردين، البنوك، الموظفين والرواتب الأساسية، المصروفات التاريخية، الإيرادات التاريخية، وسجل الرواتب المدفوعة سابقًا.
- قراءة ملفات XLSX وXLS وCSV عبر SheetJS.
- مطابقة الأعمدة تلقائيًا مع إمكانية تعديل المطابقة.
- معاينة أول الصفوف والتحقق من الحقول قبل الحفظ.
- قوالب CSV قابلة للتنزيل لكل نوع.
- حفظ المنتجات كرصيد مخزون افتتاحي مع تاريخ انتهاء الصلاحية عند توفره.
- سجلّات العمليات التاريخية لا تغيّر الأرصدة النقدية/البنكية تلقائيًا؛ هذا مقصود لتجنب مضاعفة الأرصدة.
- شعار جديد وأيقونات محدثة.
- تحديث service worker لتخزين ملف الاستيراد محليًا.

## النشر
1. احتفظ بنسخة احتياطية من المشروع وقاعدة بيانات Firestore.
2. اختبر المشروع أولًا على بيئة تجريبية أو شركة تجريبية.
3. انشر محتويات مجلد `Teyssir-ERP--main` على Vercel بنفس إعداد النشر الحالي.
4. افتح المنصة مع اتصال بالإنترنت مرة واحدة لتحميل مكتبة Excel؛ بعدها يمكن أن تكون المكتبة متاحة من ذاكرة التخزين المؤقت عند دعم المتصفح لذلك.
5. سجّل الدخول إلى الشركة، افتح زر استيراد Excel، نزّل القالب المناسب، املأه ثم ارفع ملفك وراجع المعاينة قبل الاستيراد.

## تنبيهات مهمة
- لم يُنشأ ملف Windows EXE في هذا التحديث؛ هذا الأرشيف تحديث لمصدر المنصة.
- مزامنة Firestore دون اتصال تعتمد على إعدادات Firebase والصلاحيات والاتصال، ويجب اختبارها عمليًا.
- راجع قواعد أمان Firestore: مفتاح Firebase الظاهر في الواجهة ليس بديلًا عن قواعد وصول سليمة.
- الاستيراد التاريخي لا ينشئ فواتير مبيعات أو مشتريات أصلية، ولا يحاول إعادة بناء كل الحركات المالية من الأرصدة وحدها.
- يجب اختبار أسماء الحقول والتقارير الفعلية على نسخة تجريبية قبل استيراد بيانات إنتاج حقيقية.
